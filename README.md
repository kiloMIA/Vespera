# Приглашение в Весперу

Одностраничное приглашение на первую сессию готической кампании. Сайт полностью статический и готов для GitHub Pages.

## Быстрая настройка

Откройте `dist/config.js` и замените дату, время и место встречи.

Чтобы добавить фоновую фотографию, положите файл в папку `dist/assets`, например `dist/assets/mansion.jpg`, и укажите:

```js
heroImage: "assets/mansion.jpg",
```

Если оставить пустую строку, сайт сохранит текущий атмосферный фон без фотографии.

## Google Forms

Анкета уже подключена к форме кампании. Текущие идентификаторы находятся в `dist/config.js`.

Если форма будет создана заново, подключите новую следующим образом.

Создайте Google Form с тремя вопросами:

1. Ваше имя.
2. Имя персонажа.
3. Класс персонажа.

Откройте форму, выберите «Получить предварительно заполненную ссылку», внесите различимые тестовые значения и получите ссылку. В ней будут параметры вида `entry.123456789`. Скопируйте три имени параметров в `dist/config.js`.

Адрес `action` имеет вид:

```text
https://docs.google.com/forms/d/e/FORM_ID/formResponse
```

Готовый блок настройки:

```js
googleForm: {
  action: "https://docs.google.com/forms/d/e/FORM_ID/formResponse",
  playerNameEntry: "entry.111111111",
  characterNameEntry: "entry.222222222",
  characterClassEntry: "entry.333333333"
}
```

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub и загрузите в него весь проект.
2. В **Settings → Pages → Build and deployment** выберите источник **GitHub Actions**.
3. Отправьте изменения в ветку `main`.

В проект уже добавлен workflow `.github/workflows/pages.yml`. Он публикует содержимое папки `dist` после каждого обновления ветки `main`.
